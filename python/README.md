# Python Tools

The package in `aifiar_tools` provides standard-library-only repository scanning, heuristic security auditing, SHA-256 freshness checks, patch-manifest validation, and a bounded allowlisted command runner.

Start at [the Python tools guide](../docs/python-tools.md). The CLI is `scripts/aifiar.py`. Run tests with `python -m unittest discover -s python_tests -v`.
